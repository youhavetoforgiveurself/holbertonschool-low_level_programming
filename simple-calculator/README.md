# chill calculator

just a chill simple calculator made in C. #Cisfun

## Compilation

gcc -Wall -Werror -Wextra -pedantic -std=gnu89 calculator.c -o calculator

## Run

./calculator

## Operations

The calculator has +, -, * and /.

## Numeric Behavior

the calculator uses whole numbers for now, not decimals. NOW IT WORKS W WHOLE NUMBERS AND DECIMALS WOOWIE.
